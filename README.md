## Features ๋࣭ ⭑✮💻₊ ⊹
Here are the core features:
   - A main page showing the most added games to the RAWG API platform.
   - Mini info cards on each game, showing name, platforms and genres.
   - A search bar that lets you look up name titles and find the most relevant searches.
   - About page when you click the cards, showing a more in-depth view of the games, containg about the game, plublisher, release date and more!

## How to Run locally ₊⊹ 💻
Prerequisites:

Make sure you have the following installed:
   - Node.js
   - npm (included with Node.js)
   - A valid API key

Installation:
   - 1. Clone the repository:
            - git clone [https://github.com/Itzshey/game-explorer.git](https://github.com/Itzshey/game-explorer.git)
   - 2. Navigate to the project folder:
            - cd game-explorer
   - 3. Install dependencies:
            - npm install
   - 4. Configure your API key
            - Create your local API configuration file and add your API key.
            - Make sure to follow the configuration format expected by the backend.
            - Important: Never share or commit your API key (I made this mistake once haha). Keep your configuration file listed in .gitignore.
        
Running the project:
   - Start the development server
         node server.js
     After running this command a link should pop up saying that the server is running on http://localhost:3000/home.html
     
You're all set! Enjoy exploring games! 🎮
